Nouveau : envois d'argent et remboursements automatiques (Orange Money et Moov Money). Le téléphone compose lui-même le code USSD d'envoi et saisit le code secret.
Le code secret est chiffré et reste dans le téléphone (jamais envoyé au site).
Pour l'activer : ouvrez l'application > « Envois d'argent », activez l'interrupteur, autorisez les appels et l'accessibilité, puis enregistrez le code secret de chaque opérateur.
Mise à jour directe par-dessus la version 2.4.0 (pas besoin de désinstaller).
